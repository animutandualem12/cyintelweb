Cyber Security Intelligence
A web-based cybersecurity news and threat-intelligence platform for publishing, organizing, and sharing cybersecurity information.

Live website: https://cyintelweb-1.onrender.com
Overview
Cyber Security Intelligence brings cybersecurity news, technology updates, and intelligence articles together in one website. The home page highlights recent threat-intelligence content and articles, while the navigation provides access to the main content areas and site-management pages.

The platform is intended to support cybersecurity awareness, threat monitoring, research, and information sharing.
Website sections
The current website interface includes the following sections:
- Home – Displays the latest threat-intelligence item and the latest articles.
- News – Provides access to cybersecurity news content.
- Technology – Organizes technology-related cybersecurity articles and updates.
- Intelligence – Provides access to cyber-intelligence content.
- Add Content – Entry point for adding website content. Access and permissions depend on the application's authentication settings.
- Ads Manager – Entry point for managing website advertisements, where enabled.
- Trending Topics – Highlights topics such as ransomware, APT groups, zero-day vulnerabilities, phishing, malware, data breaches, CISA updates, vulnerabilities, and cybersecurity jobs.
- Featured content carousel – Displays highlighted content in the home-page sidebar.
Technology
The application has been developed using the following technologies, based on the project setup:
- Python – Application programming language.
- Flask – Web application framework.
- MongoDB – Database.
- HTML, CSS, JavaScript – Front-end presentation and interaction.
- Waitress – Production WSGI server for Windows or other supported environments.
- Render – Hosting platform for the live deployment.
